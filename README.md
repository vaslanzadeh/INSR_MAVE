### Step-by-Step Analysis
First, download the Zenodo dataset and place it in the working directory.
1. **Aligning PacBio HiFi reads to GBA1 amplicon**  
   - Run "process_PacBio_sequencing.py". This will process m84140_250314_170434_s1.hifi_reads.bc1012.fastq.gz (GEO: GSE277112 ), PacBio Revel       sequencing output. It will map reads to the amplicon (GBA1_PacBio.gb) using minimap2. The outputs are GBA1_PacBio_aligned.csv and GBA1_PacBio_filtered.csv files.

2. **Linking barcodes to variants and creating barcode-variant table**  
   - Run "pbData_analysis.ipynb".  It wiinputs are 
   - This notebook processes GBA1_PacBio_aligned.csv and GBA1_PacBio_filtered.csv files from step 1 and generates barcode-variant table along with stat around the coverage and QC.
     
3. **Trim adapters from Flow-Seq sorted barcode sequencing**
   - Run trimmomatic_run.sh to remove 30nts adapters from Ilumina barcode sequenicng reads. This run requires the following fastq files which are available from GEO: GSE277112. 
   GBA1-Bin1_S1_L001_R1_001.fastq.gz
   GBA1-Bin2_S2_L001_R1_001.fastq.gz
   GBA1-Bin3_S3_L001_R1_001.fastq.gz
   GBA1-Bin4_S4_L001_R1_001.fastq.gz
   - The output would be
   GBA1_R1_Bin1_trimmed.fastq.gz
   GBA1_R1_Bin2_trimmed.fastq.gz
   GBA1_R1_Bin3_trimmed.fastq.gz
   GBA1_R1_Bin4_trimmed.fastq.gz

4. **Analysis of trimmed reads using Enrich2 for counting barcodes in each bin**  
   - Use the provided configuration files (in the `Enrich2_counts` folder) to run enrich2_run.sh. This will process the trimmed reads from step 3.
   - This step counts barcode frequencies in each sorted bin (based on Illumina sequencing of gDNA extracted from cells).  

3. **Variant Scoring**  
   - Run `flowSeq_analysis.ipynb` to process Enrich2 count file (enrich2_counts/tsv/sort_sel/main_barcodes_counts_unfiltered.tsv) and compute barcode/variant scores.  
   - This notebook uses the barcode–variant table generated by `pbData_analysis.ipynb` (results/variants/barcode_variant_enrich2.tab).
   - This notebook, also generates some of the figures used in the manuscript and also some other additional QC figures.

---

**Note:**  
If you only need to analyse variant scores, you can directly run `gba1_flowSeq_analysis.ipynb`, as all the required files are included in the Zenodo dataset.
